| Funktion                            | Windows 11                                              | Linux (UEFI)                        | macOS Intel                            | macOS Apple Silicon                                |
| ----------------------------------- | ------------------------------------------------------- | ----------------------------------- | -------------------------------------- | -------------------------------------------------- |
| **Boot-Einträge auflisten**         | `bcdedit /enum firmware`                                | `efibootmgr -v`                     | `bless --info` / `nvram -p`            | **nicht über UEFI-NVRAM wie PC**                   |
| **Aktuelle Bootreihenfolge**        | `bcdedit /enum firmware` → `{fwbootmgr}` `displayorder` | `efibootmgr` → `BootOrder`          | `bless --info` / `nvram`               | Apple Startup Security / Boot Picker               |
| **Standard-Boot setzen**            | `bcdedit /set {fwbootmgr} displayorder {ID} /addfirst`  | `efibootmgr -o XXXX,YYYY,...`       | `bless --setBoot ...`                  | Apple-spezifisch                                   |
| **Nur nächsten Boot setzen**        | `bcdedit /bootsequence {ID}`                            | `efibootmgr -n XXXX`                | `bless --nextonly ...`                 | Apple-spezifisch                                   |
| **UEFI/Boot-Konfiguration starten** | `shutdown /r /fw /t 0`                                  | `systemctl reboot --firmware-setup` | `bless --nextonly --firmware`          | `systemctl` nicht anwendbar; Apple Startup Options |
| **Eintrag löschen**                 | `bcdedit /delete {ID}`*                                 | `efibootmgr -b XXXX -B`             | kein gleichwertiges UEFI-NVRAM-Konzept | —                                                  |
